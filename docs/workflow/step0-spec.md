## 기능명

To-Do List Application (MSW 기반 / React 18 + Vite)

## 배경 & 목적

- recruit.saige.ai FE 역량 테스트. REQUIREMENT.md의 기능/비기능 요구사항 충족.
- `/api/todos` CRUD(MSW, localStorage 백엔드) 위에 추가/수정/완료/다중삭제/검색/페이지네이션
  + 추가기능(Pin·상태필터·낙관적 업데이트·삭제 Undo·다크모드) 구현.

## 기능 목록

**필수(요구사항)**

- [ ] To-Do 추가: 내용 + 기한(날짜) 입력 (높음)
- [ ] 입력 검증: 할일 필수 / 과거 날짜 금지 (높음)
- [ ] 인라인 행 수정(내용·기한) (높음)
- [ ] 완료 토글 + 완료 시각 표시(취소선 등) (높음)
- [ ] 다중선택 삭제 + 전체선택 (높음)
- [ ] 마감 3일 이내 강조 표시 (높음)
- [ ] 페이지네이션(Page Size 5/10/20) (높음)
- [ ] 검색 + 키워드 영속(브라우저 재오픈 유지) (높음)

**추가(선택 확정)**

- [ ] Pin: 상단 고정/해제 (클라이언트 전용, 영속) (중간)
- [ ] 상태 필터: 전체/진행중/완료 (중간)
- [ ] 낙관적 업데이트: 완료 토글·삭제 즉시 반영 (중간)
- [ ] 삭제 실행취소(Undo 토스트) (중간)
- [ ] 다크모드 (낮음)

## 유저 시나리오

1. 상단 폼에 내용+기한 입력 → 추가 → 목록에 반영
2. 행 체크박스로 완료 토글 → 취소선/흐림 표시 (낙관적 즉시 반영)
3. 행 편집 진입 → 내용·기한 인라인 수정 → 저장(PUT)
4. 여러 행 선택(전체선택 포함) → 삭제 → Undo 토스트로 일정시간 내 복구 가능
5. 검색어 입력 → 목록 즉시 필터 → 브라우저 닫았다 열어도 검색어/필터 유지
6. Pin 클릭 → 해당 항목 상단 고정
7. 페이지 사이즈 변경(5/10/20) + 페이지 이동

## 예외 & 엣지케이스

- 빈 내용/공백만 → 추가·저장 차단 + 메시지
- 과거 날짜 → 차단 + 메시지(오늘 기준 경계)
- API 실패 → 에러 표시(QueryCache/MutationCache 토스트) + 낙관적 롤백
- 빈 목록 / 검색결과 0건 → 각각 빈 상태 UI
- 페이지 마지막 항목 삭제 시 페이지 보정
- 마감 지남(overdue) vs 3일 이내(near) 구분 표시

## 상태 설계 (요약)

- **서버 상태(React Query v5)**: `['todos']` 쿼리 + create/update/delete 뮤테이션.
  완료토글·삭제는 onMutate 낙관적 업데이트 + 실패 롤백. 필터/검색은 캐시 덮어쓰기 ❌.
- **공유 클라이언트 상태(Zustand + persist)**: selection(비영속) / pin / prefs(keyword·filter·pageSize) / theme.
- **로컬/파생(렌더 중 계산)**: 검색·필터·정렬(핀 우선)·페이지 슬라이스, near/overdue, 전체선택 상태.
